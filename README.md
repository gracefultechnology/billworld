# U.S. bill-pay research

Companies and agencies a U.S. senior is likely to pay, with each one's official pages for
viewing a bill, paying, setting up and cancelling autopay, and checking past statements.

## Files

| Path | Contents |
|---|---|
| `categories/<group>.json` | Billers, one file per bill group (electric, gas, water-sewer, credit-cards, medicare, …). |
| `rosters/*.csv` | Public lists of utilities, banks, credit unions, water systems, telecoms, hospitals and other billers. |
| `rosters/discovery_resources.json` | Datasets, directories and APIs for finding more billers. |
| `rosters/payment_platform_usage_xref.csv` | Which payment platform (Paymentus, Invoice Cloud, SmartHub, …) each biller uses. |
| `build.py` | Builds `billers.json`, `billers.csv` and `COVERAGE.md` from `categories/`. |
| `make_xlsx.py` | Builds `billers.xlsx` from `billers.csv` (needs `xlsxwriter`). |
| `finalize.py` | Merges new research files into the group files. |
| `clean_notes.py` | Removes research commentary from `notes` and `senior_programs`. |
| `SCHEMA.md` | Entry format and research rules. |
| `COVERAGE.md` | Counts, link fill rates and per-state coverage (generated by `build.py`). |

```bash
python3 build.py
python3 make_xlsx.py
```

## Downloads

The built spreadsheet, CSV and JSON are attached to the
[latest release](https://github.com/eliza-research/billpay-research/releases/latest) rather than
committed (the JSON is about 80 MB):

- `billers.xlsx`: README, coverage, Detailed and All billers sheets
- `billers.csv`: one row per biller
- `billers.json`: every entry with all fields

Raw dataset downloads used to build the rosters are not included; `rosters/discovery_resources.json`
lists where to get them.

## Entry fields

| Field | Meaning |
|---|---|
| `name`, `parent_company`, `aliases` | Biller name, owner, other names it uses |
| `bill_type` | electric, gas, water, credit-card, medicare-advantage, property-tax, … |
| `entity_type` | investor-owned, cooperative, municipal, government, private, … |
| `service_area`, `service_area_detail` | State codes (`US` = national) and the area served |
| `approx_customers` | Approximate customers or members |
| `website`, `login_url`, `help_center_url` | Official site, account sign-in, help center |
| `links.view_bill` | How to view a bill |
| `links.pay_bill` | Ways to pay (online, phone, mail, in person) |
| `links.autopay_setup`, `links.autopay_cancel` | Set up and stop automatic payments |
| `links.statements_history` | Past statements and payment history |
| `links.paperless` | Paperless billing |
| `links.payment_assistance` | Senior discounts, hardship and bill-help programs |
| `phone_customer_service`, `phone_pay_by_phone` | Phone numbers |
| `mail_payment_address` | Where to mail a payment |
| `payment_processor` | Platform behind the pay page (Paymentus, Kubra, Invoice Cloud, …) |
| `app` | iOS and Android app links |
| `senior_programs` | Senior or fixed-income discounts and protections |
| `notes` | Practical tips for paying this biller |
| `tier` | `detailed` (help pages researched) or `roster` (identity and website from a public roster) |
| `verified` | `true` if the pages were fetched and matched during research |
| `last_checked` | Date the links were last checked |

Some entries also carry public identifiers for matching to other data: `eia_utility_id`,
`sdwis_pwsids`, `ncua_charter`, `fdic_cert`, `cms_contracts`, `county_fips`.
A missing link is `null`.

## What matters for the product

- **A few platforms serve most small billers.** Co-ops mostly use NISC SmartHub or SEDC;
  municipal utilities use Invoice Cloud, Paymentus, Tyler, Xpress Bill Pay and similar;
  hospitals mostly use Epic MyChart. One flow per platform covers thousands of billers.
- **Energy supplier charges usually appear on the utility bill.** Outside Texas and Georgia,
  a senior with a retail electric or gas supplier usually pays the utility, not the supplier.
- **Cancelling autopay is the least documented step.** Many billers only explain it after
  sign-in.
- **Third-party pay sites cause confusion.** Several billers say doxo and similar sites are
  not affiliated with them. Send people to the biller's own pay page or its listed processor.
- **Senior programs are common:** 65+ rates, third-party shutoff notices to a relative,
  medical-equipment protections, budget billing, LIHEAP, and property tax deferral.
- **Mergers move payments.** Entries name the company customers pay now
  (for example UScellular → T-Mobile, Discover → Capital One).
- **To find which utility serves an address,** use service-territory data (HIFLD electric and
  gas territories, EPA water system boundaries, FCC broadband map); names alone are not enough.

## Finding more billers

| Need | Source |
|---|---|
| Electric utilities | EIA Form 861; HIFLD Electric Retail Service Territories; NRECA and APPA directories |
| Gas utilities | HIFLD Natural Gas Service Territories; EIA-176 |
| Retail energy suppliers | Texas PUC REP directory; state utility commission supplier lists |
| Water systems | EPA SDWIS; EPA Community Water System Service Area Boundaries |
| Phone, internet, cable | FCC National Broadband Map; FCC Form 499 filers; NTCA and ACA Connects members |
| Banks and credit unions | FDIC BankFind API; NCUA call report data |
| Credit cards | CFPB Credit Card Agreement Database |
| Mortgage servicers and collectors | NMLS Consumer Access; CFPB complaint database |
| Medicare plans | CMS plan, contract and enrollment files; Medicare Plan Finder |
| Insurers | NAIC Consumer Insurance Search; state insurance departments |
| Hospitals, equipment, pharmacies | CMS hospital and supplier files; NPPES |
| Taxes, DMV, tolls | USA.gov state directories; E-ZPass Group |
| Payment platforms | Paymentus, Kubra and Invoice Cloud client lists; CheckFree and RPPS biller directories |
| Bill help | LIHEAP Clearinghouse; NCOA BenefitsCheckUp; Eldercare Locator; 211 |
